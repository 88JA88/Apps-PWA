# État — Mon congélateur

## Application

- PWA domestique pour gérer les denrées du congélateur.
- Les denrées et contenants sont saisis librement.
- Les portions et étagères utilisent des choix fixes.
- Les données restent dans le stockage local du navigateur et sont exportables/importables en JSON.

## Publication

- Préparée pour GitHub Pages dans le dépôt `88JA88/Apps-PWA`, sous le dossier `Mon-congelateur/`.
- Manifeste et service worker propres à l’application.
- Icône commune JA-Applications avec le vert clair propre à Mon congélateur.

## Vérifications

- Manifeste JSON valide.
- Ressources statiques et cache hors ligne déclarés.
- Le fichier JSON personnel de sauvegarde n’est pas destiné à la publication.
